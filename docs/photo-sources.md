# Foto dokumentasi senam putra GCL

Foto berikut dipakai pada landing page dan visual halaman masuk. Semua berkas WebP mempertahankan proporsi foto sumber; tidak ada generasi atau retouching AI. Sumber, kredit fotografer, dan lisensi ditampilkan untuk pengunjung pada `/photo-credits`.

Versi WebP mengikuti lisensi pada foto sumber masing-masing. Berkas berstatus public domain mempertahankan status tersebut. Foto hanya menunjukkan kegiatan olahraga yang didokumentasikan pada sumbernya.
